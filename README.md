# 隔夜雷达

面向个人自选池的 A 股 14:30 隔夜筛选仪表盘。策略只在市场与个股硬门槛同时通过时生成条件式计划；没有合格机会时保持空仓。

## 本地运行

```bash
python3 -B server.py --host 127.0.0.1 --port 8765
```

打开 `http://127.0.0.1:8765`。页面每 60 秒刷新，企业微信配置保存在本机 `data/` 目录，该目录不会提交到 Git。

## GitHub Actions 每日推送

工作流 `.github/workflows/daily-push.yml` 在工作日北京时间 14:31 运行。GitHub 定时任务可能排队延迟；程序只允许在北京时间 14:30-15:00 且行情日期为当天时推送，休市或过时行情会自动跳过。

在仓库中配置：

1. 打开 `Settings` -> `Secrets and variables` -> `Actions`。
2. 新建 Repository secret，名称为 `WECOM_WEBHOOK`。
3. 值填写企业微信“消息推送”生成的完整官方 Webhook。
4. 打开 `Actions` -> `Daily A-share push`，可使用 `Run workflow` 手动验证任务能否完成；非决策窗口会安全跳过推送。

Webhook 不得写入代码、工作流文件、提交记录或聊天消息。已经泄露的 Webhook 应先在企业微信中删除并重新创建。

## 交易口径

- 决策数据截断到北京时间 14:30。
- 买入后按 A 股 T+1 约束处理，下一交易日最迟 10:00 退出可成交数量。
- 红灯市场、关键数据缺失、公告未核验或个股硬门槛失败时不建立新仓。
- 自动筛选仅供研究参考，不构成个性化投资建议。
